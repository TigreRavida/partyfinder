# PartyFinder

App para encontrarse con tu grupo en fiestas electrónicas (MVP: Loveland).
PWA en React + Vite. Backend en Supabase.

## Desarrollo local
```bash
npm install
# crear .env con las claves de Supabase (ver .env.example)
npm run dev
```

## Variables de entorno
```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

## Deploy
Vercel: conectar el repo, agregar las variables de entorno, deploy automático.
